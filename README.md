# coc-project-ludo-dice-simulator
It's a simple ludo dice simulation based on the Stochasting modelling to know the probability of each combination of sum of output get by rolling 2 dice. with theoretical percentage comparing in c language.

it performs a simulation of about 1 million no of times.

**Function use:**

1)rand(),time(),array,for_loop.

2)math:division,addition,conversion.

**how to compile:** : gcc ludo_dice_simulator.c -o simulator -lm

**how to run** : simulator
